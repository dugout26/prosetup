윈도우 마우스 가속 끄는 법 — '포인터 정확도 향상' 해제 (프로 세팅 기준)

마우스 가속은 손을 빨리 움직일수록 커서가 더 멀리 가게 만드는 기능입니다. 같은 거리를 움직여도 속도에 따라 결과가 달라져 에임·클릭 위치가 일정하지 않게 됩니다. 프로 세팅 가이드는 대부분 이 기능을 끄는 것에서 시작합니다.

제품별 사용 선수감도 변환기마우스 가속 끄기LoL 모니터 가이드원딜 마우스
한 줄 결론 — 마우스 속성 → 포인터 옵션 → '포인터 정확도 향상' 체크 해제. 윈도우 11·10 모두 같은 창이고, main.cpl로 바로 열 수 있습니다.

윈도우 버전별 경로

버전마우스 속성 여는 경로
윈도우 11설정 → Bluetooth 및 장치 → 마우스 → 추가 마우스 설정
윈도우 10설정 → 장치 → 마우스 → 추가 마우스 옵션
공통(빠른 방법)Win + R → main.cpl → 엔터

윈도우 11

  1. 시작 → 설정 → Bluetooth 및 장치 → 마우스
  2. 아래쪽 추가 마우스 설정 클릭 → '마우스 속성' 창이 열림
  3. 포인터 옵션 탭 → 포인터 정확도 향상 체크 해제 → 확인

윈도우 10

  1. 시작 → 설정 → 장치 → 마우스 → 추가 마우스 옵션
  2. 포인터 옵션 탭 → 포인터 정확도 향상 체크 해제 → 확인

빠르게 여는 법: Win + R → main.cpl 입력 → 엔터.

같이 확인할 것

  • 포인터 속도는 기본값(가운데, 11칸 중 6번째)이 1:1입니다. 감도는 마우스 DPI와 게임 안에서 조절하는 편이 계산하기 쉽습니다.
  • LoL은 윈도우 커서를 그대로 쓰는 게임이라 윈도우 가속·포인터 속도가 체감에 바로 영향을 줍니다. LCK 선수 중 DPI가 확인된 18명의 중앙값은 800이고, 많이 쓰는 값은 800(8명), 1800(2명), 400(1명), 650(1명)입니다.
  • 마우스 제조사 소프트웨어(G HUB, Synapse 등)에 가속·각도 보정 옵션이 따로 있으면 그것도 끕니다.
  • 설정을 바꾼 뒤에는 감도 변환기로 cm/360을 확인해 두면 장비를 바꿔도 같은 감도를 맞출 수 있습니다.

자주 묻는 질문

마우스 가속을 끄면 뭐가 달라지나요?

손을 움직인 거리만큼만 커서가 움직입니다. 빠르게 휘둘러도 같은 거리면 같은 위치로 가서 에임·클릭 위치가 일정해집니다.

포인터 정확도 향상을 끄면 커서가 느려진 것 같아요.

가속이 빠지면서 빠른 동작 때 덧붙던 이동량이 사라진 것입니다. 포인터 속도는 기본값(6/11)에 두고 마우스 DPI로 맞추세요.

게임 안에서 원시 입력(Raw Input)을 켜면 윈도우 설정은 상관없나요?

원시 입력을 쓰는 게임은 윈도우 가속 영향을 받지 않습니다. LoL처럼 윈도우 커서를 그대로 쓰는 게임은 윈도우 설정이 그대로 적용됩니다.

LCK 프로들은 DPI를 얼마로 쓰나요?

LCK 선수 중 DPI가 확인된 18명의 중앙값은 800이고, 많이 쓰는 값은 800(8명), 1800(2명), 400(1명), 650(1명)입니다.
