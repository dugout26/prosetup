## 1. 기술 SEO / AI SEO

근거 있는 것:
- 구글 AI Overviews·AI Mode는 일반 검색과 같은 랭킹·품질 시스템을 씀. 구글 2026-05 가이드는 "남들이 다 가진(commodity) 콘텐츠가 아닌 고유 콘텐츠"를 핵심으로 봄 → **우리만 가진 집계 수치**(사용률, 포지션 평균 대비 eDPI, 장비 변경 이력)가 AI 인용 소재.
- ChatGPT 검색은 OAI-SearchBot 허용 + Bing 색인에 일부 의존 → IndexNow + Bing 웹마스터 도구 등록.
- 네이버 AI 브리핑은 질의 20%+를 커버하고 자사 UGC(블로그·카페) 비중이 큼 → 네이버 블로그에 요약을 올리고 사이트로 링크하는 방식 검토(효과 미검증).

근거 없음·과장:
- llms.txt: 구글은 의미 없다고 밝혔고, 97%가 요청 0건이었다는 집계가 있음.
- "AI용 청킹·리라이트": 구글이 불필요하다고 명시.
- FAQ 리치결과: 2026-05부터 구글에서 노출 안 됨.

우선순위 수정 목록:
1. 네이버 서치어드바이저 등록(`VERIFY_NAVER`) + sitemap 제출 + `rss.xml`(장비 변경 로그 기반)
2. 항목별 확인일(`checked`) → 페이지별 lastmod·dateModified, 화면에 "2026-11-02 확인"
3. 선수 페이지 제목을 실제 검색어로: `{kr} 마우스·키보드·감도(DPI) — {팀} {포지션} 장비`. 설명문에는 실제 제품명
4. about.html(운영·출처 기준·신뢰도·업데이트 로그) + footer 링크
5. 선수별 고유 요약 1줄(예: "미드라이너 중 n명이 같은 마우스, eDPI는 포지션 평균 대비 +x%")
6. IndexNow(Bing·네이버), thanks.html noindex, submit.html은 sitemap에서 제외
7. 커스텀 도메인은 일찍 정할수록 좋음(이전 비용 회피)

## 2. 한국 수요 (자동완성 근거)

1. **감도 변환기**: 감도 변환기·배그 감도 변환기·발로란트 오버워치 감도 변환. 한국어 경쟁 페이지는 약함(PUBG 미지원·얇은 페이지). LoL은 3D 감도가 없어 변환 대상에서 제외.
2. **LoL 선수 페이지 심화**: 페이커 마우스 감도·그립·마우스패드, 쵸비 dpi·마우스가속. 그립·가속 필드가 없음.
3. **발로란트 프로 세팅**: 조준선(크로스헤어 코드)·래피드 트리거 설정·감도.
4. **배그**(신규 게임 1순위): 배그 프로 마우스 순위·감도·그립. 한국어 경쟁 거의 없음.
5. **오버워치 OWCS Korea**: 중간 규모.
6. 일반 추천(마우스·키보드 추천): 수요는 크지만 경쟁 과열. "프로 실사용 순위"로 차별화.
7. 낮음: 스트리머 장비(분산), CS2(한국 수요 미미), FC온라인, 로스트아크.

## 3. 데이터 소스 확장성

- prosettings 커버리지: CS2 932, 발로 680, 포트나이트 324, LoL 167, R6 104, Apex 73, PUBG 64, 오버워치 36 … 총 약 2,450명. 이 중 약 60%는 한국 수요가 낮은 CS2·발로 서양 선수. 한국 독자에게 추가 가치가 있는 건 한국 선수 약 100명 수준. 일부 한국 로스터는 낡은 정보(옛 광동 로스터 등).
- 결론: **대량 수입은 법적 위험 높음 + 이득 작음.** prosettings는 개별 선수 조회용으로만 쓰고, 2차 출처(팀·스폰서 공지, 방송, Liquipedia)로 확인한 값만 출처·확인일과 함께 게시하는 방식을 권장.
- 발로란트 기존 218명 처리안: (a) prosettings에 라이선스·제휴 문의 (b) 한국 팀(VCT Pacific 한국팀, 한국 선수) 중심으로 줄이고 교차 확인으로 재구축 (c) 현행 유지(위험 감수).
- 대안 출처: Liquipedia(CC-BY-SA 3.0 — 개별 사실 인용+출처는 OK, 표·문장을 재게시하면 ShareAlike 적용, HTML 자동 수집 금지), 팀·스폰서 공지(1차 출처), 스트리머 방송 페이지(수작업).
- 확장 순서: ① LoL 해외 한국 선수 + LCK CL ② 오버워치 OWCS Korea(Liquipedia hardware 목록) ③ VCT Challengers Korea ④ 배그 한국 프로(팀·스폰서) ⑤ 한국 스트리머(수작업)
